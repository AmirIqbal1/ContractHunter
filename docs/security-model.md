# Security model

ContractHunter is for authorised analysis only. It is a single-user local tool with no authentication; do not expose it directly to an untrusted network.

Repository content is hostile data, never instructions. GitHub sources are restricted to validated HTTPS repository URLs and refs. Clone paths, source paths, imports, submodules, and generated workspaces remain inside assigned roots.

Dependency preparation accepts only pinned approved HTTPS Git submodules and lockfile-backed npm dependencies. npm uses isolated configuration/cache, `npm ci`, disabled lifecycle scripts, bounded output/timeouts, and no host credentials. Repository scripts, Makefiles, Hardhat setup, arbitrary shell, and `forge install` are not executed.

Compiler selection uses strict Foundry configuration or Solidity pragma parsing. Only stable resolver-produced versions reach `solc-select`; installation and compiler processes are bounded.

AI receives bounded, validated repository context only. Tools, web access, filesystem access, shell commands, arbitrary Solidity, RPC endpoints, wallets, private keys, forks, FFI, and live-chain actions are unavailable. AI may propose structured data only.

Verification harnesses are generated by ContractHunter from a strict schema. Plans, source allowlists, manifests, hashes, and content fingerprints are revalidated before execution. AI proposes structured plan data only: no arbitrary Solidity, commands, cheatcodes, calldata, RPC, forks, wallets, private keys, FFI, or live-chain transactions. Verification requires supported Linux network/PID isolation, resource limits, a sanitised environment, non-root execution, dropped capabilities, `no-new-privileges`, no Docker socket, and no required host networking; missing isolation fails closed.

## Evidence hierarchy

```text
Static Finding → Investigation → Invariant → Hypothesis → Dynamic Evidence → Verified
```

Only authoritative supporting dynamic evidence from a completed valid local verification may cause the `verified` transition. Process success, infrastructure failures, parser ambiguity, and incomplete output cannot verify a hypothesis.
